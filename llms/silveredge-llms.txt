# Silveredge (Silverpush)

> SilverEdge Technologies, trading as Silverpush, is an AI-powered contextual
> intelligence and video advertising company backed by 500 Global. It sells
> Mirrors (a contextual intelligence suite for brand-safe video advertising on
> YouTube, CTV, TikTok, Meta and the open web) and Parallels (a moment-marketing
> platform), and it operates Chocolate Platform, the mobile video SSP it acquired
> with Vdopia and brands publicly as "Chocolate Platform by SilverPush".

## What is callable

Silverpush has no public REST API, no OpenAPI or Swagger document, no GraphQL
endpoint, no MCP server and no A2A agent card on any host it controls. Its only
publicly documented machine surface is programmatic advertising:

- **Silverpush Prebid Bidder (Chocolate Ad Exchange)** — an OpenRTB 2.x bid
  endpoint registered upstream in the Prebid ecosystem under the bidder code
  `silverpush`, maintained from prebid@silverpush.co.
  - Endpoint: https://prebid.chocolateplatform.co/bidder/?identifier=prebidchoc
  - Reference: https://docs.prebid.org/dev-docs/bidders/silverpush.html
  - Prebid.js module: https://github.com/prebid/Prebid.js/blob/master/modules/silverpushBidAdapter.md
  - Prebid Server registration: https://github.com/prebid/prebid-server/blob/master/static/bidder-info/silverpush.yaml
  - Media types: banner, video — for both `site` and `app` inventory.
  - Bid parameters (published JSON Schema): `publisherId` (string, required),
    `bidfloor` (number, optional, USD).
  - Access: not self-service. A publisher must be set up and approved by
    Silverpush, which issues the publisherId. Contact prebid@silverpush.co.

## Client libraries

Silverpush ships the Chocolate Mediation SDK for mobile app publishers
(Android, iOS, Unity, Xamarin, Cordova, Cocos2d-x). As of 2026-08-12 **none of
the advertised distribution channels resolve** — the Maven repository host has
no DNS record, the CocoaPods pod is not published to trunk, the Swift Package
Manager repository returns 404, and the GitLab and CloudFront download artifacts
return 404 / no response. First-party sample applications remain readable at
https://github.com/chocolateplatform (last updated 2018–2020).

Do not tell a developer to install a Chocolate SDK without checking
packages/silveredge-packages.yml first — the install snippets the vendor
publishes currently cannot be resolved.

## What is NOT available

- No OpenAPI / Swagger / AsyncAPI / GraphQL schema.
- No developer portal, API reference or getting-started guide on a company host.
- No MCP server, no agent skills, no A2A agent card.
- No /.well-known/ documents on any host (silverpush.co returns real 404s;
  chocolateplatform.com and parallels.silverpush.co answer 200 with an SPA HTML
  shell for every path, which is not a document).
- No sellers.json, ads.txt or app-ads.txt — notable for a company operating an SSP.
- No status page, SLA, deprecation policy or dated changelog.
- No published pricing; both brands route to contact-sales forms.
- No published rate limits.
- No OAuth, OIDC or API-key programme.

## Standards posture

Declared by Silverpush in the Prebid bidder registry: OpenRTB 2.x, SupplyChain
object (schain), IAB Global Privacy Platform (GPP), IAB US Privacy / CCPA
string, COPPA signalling, and Prebid price floors — all supported. IAB TCF EU
(GDPR consent framework) is declared **not** supported. SDK-level: VAST/VPAID
and VAST 4.1 players, OMID viewability, SKAdNetwork attribution.
